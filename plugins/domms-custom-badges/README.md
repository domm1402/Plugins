# Domms Custom Badges

A Valenced plugin that adds custom image badges and Discord-style badge presets to your own Discord profile inside Valenced.

## Features

- Add custom badges using direct HTTP or HTTPS image URLs.
- Preview each badge before adding it.
- Give badges a custom label.
- Remove custom badges whenever you want.
- Use the built-in Discord-style badge presets.
- Toggle whether all profile badges are shown.

## How it works

Badges are stored locally on your device and are only applied to your own profile in your Valenced app. They are not synced to other users or shared across devices.

Use a URL that returns the image itself. The URL does not need a `.png` or `.jpg` extension, but an ordinary webpage URL will not work.

## Installation

Add the Domm's Valenced Plugins repository to Valenced:

```
https://domm1402.github.io/Plugins/
```

Then find **Domms Custom Badges** in the repository and install it.

## Compatibility

- Valenced API: `>=1 <2`
- Discord: `>=351.1`
