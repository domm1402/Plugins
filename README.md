# Domm's Valenced Plugins

A collection of plugins for the **Valenced Android Discord client**, maintained by **Niche Games**.

## Available plugins

### Domms Custom Badges
Add your own image badges to your Discord profile inside Valenced. Add badges using direct HTTP or HTTPS image URLs, choose from built-in Discord-style badge presets, preview and remove custom badges, and toggle whether all profile badges are shown.

**Important:** custom badges are stored locally on your device and are displayed on your own profile in your Valenced app. They are not synced to other users or shared across devices. Image links must return the image itself, not a webpage containing an image.

[Open Domms Custom Badges](https://github.com/domm1402/Plugins/tree/main/plugins/domms-custom-badges)

## Add this repository to Valenced

Use this repository URL in Valenced's plugin repository manager:

```
https://domm1402.github.io/Plugins/index.json
```

Browse the repository in Valenced to install available plugins and receive published updates.

## Repository development

This repository follows the [Valenced plugin template](https://github.com/Valenced/valenced-plugin-template). Each plugin lives in its own folder under `plugins/` and has its own `manifest.json`.

To build and package plugins, see the template's build instructions below and the workflows in this repository.
